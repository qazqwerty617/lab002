# Lab 2: Parallel Matrix Multiplication

## Описание проекта

Этот проект содержит реализацию последовательного и параллельного умножения матриц для лабораторной работы №2. Параллельная версия использует алгоритм Фокса с MPI для распределения вычислений между процессами.

## Файлы проекта

- `serial_mm.cpp` - Последовательная реализация умножения матриц
- `parallel_mm_fox.cpp` - Параллельная реализация с использованием алгоритма Фокса и MPI

## Ключевые наблюдения

- **Для очень маленьких размеров матриц** (например, 10), параллельные алгоритмы показывают отрицательное ускорение, что указывает на то, что они медленнее последовательного алгоритма из-за накладных расходов.

- **С увеличением размера матрицы** параллельные алгоритмы демонстрируют значительные улучшения производительности и положительное ускорение.

- **Увеличение количества процессоров** (с 1 до 4 до 9) в целом приводит к большему ускорению для больших размеров матриц.

- **Времена выполнения с 1 процессором** последовательно немного выше, чем времена последовательного алгоритма, что указывает на некоторую накладную нагрузку даже при однопроцессорной параллельной реализации.

## Компиляция и запуск

### Последовательная версия
```bash
g++ -O2 -std=c++11 serial_mm.cpp -o serial_mm
./serial_mm
```

### Параллельная версия (требует MPI)
```bash
mpic++ -O2 -std=c++11 parallel_mm_fox.cpp -o parallel_mm_fox
mpirun -np <p> ./parallel_mm_fox
```

**Примечание:** Количество процессов `p` должно быть полным квадратом (q*q), а размер матрицы должен быть кратен q.

## Требования

- C++11 компилятор
- MPI (OpenMPI или MPICH) для параллельной версии
- Достаточно памяти для больших матриц
