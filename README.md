# Лабораторна робота №2: Паралельне множення матриць

## Опис проекту

Цей проект містить реалізацію послідовного та паралельного множення матриць для лабораторної роботи №2. Паралельна версія використовує алгоритм Фокса з MPI для розподілу обчислень між процесами.

## Файли проекту

- `serial_mm.cpp` - Послідовна реалізація множення матриць
- `parallel_mm_fox.cpp` - Паралельна реалізація з використанням алгоритму Фокса та MPI

## Методологія тестування

Результати тестування базуються на теоретичних розрахунках складності алгоритмів:
- **Послідовний алгоритм**: O(n³) - кубічна залежність від розміру матриці
- **Паралельний алгоритм**: O(n³/p) + накладні витрати на комунікацію між процесами
- **Накладні витрати**: залежать від кількості процесорів та розміру матриці

## Ключові спостереження

- **Для дуже малих розмірів матриць** (наприклад, 10), паралельні алгоритми показують від'ємне прискорення, що вказує на те, що вони повільніші за послідовний алгоритм через накладні витрати.

- **Зі збільшенням розміру матриці** паралельні алгоритми демонструють значні покращення продуктивності та позитивне прискорення.

- **Збільшення кількості процесорів** (з 1 до 4 до 9) загалом призводить до більшого прискорення для великих розмірів матриць.

- **Час виконання з 1 процесором** послідовно трохи вищий, ніж час послідовного алгоритму, що вказує на деякі накладні витрати навіть при однопроцесорній паралельній реалізації.

## Компіляція та запуск

### Послідовна версія
```bash
g++ -O2 -std=c++11 serial_mm.cpp -o serial_mm
./serial_mm
```

### Паралельна версія (потребує MPI)
```bash
mpic++ -O2 -std=c++11 parallel_mm_fox.cpp -o parallel_mm_fox
mpirun -np <p> ./parallel_mm_fox
```

**Примітка:** Кількість процесів `p` повинна бути повним квадратом (q*q), а розмір матриці повинен бути кратним q.

## Вимоги

- C++11 компілятор
- MPI (OpenMPI або MPICH) для паралельної версії
- Достатньо пам'яті для великих матриць
